# Konfigurator

Transformer Configurator.

Website: https://josuahesser2026.github.io/Konfigurator/

GitHub Pages deploys the form automatically when changes are pushed to `main` or the publishing branch.

The password prompt is only a client-side visual barrier. The site and source remain public on GitHub Pages; do not put confidential information on it. Use hosting with server-side authentication for real access control.

For local development, open `index.html` in a browser or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
